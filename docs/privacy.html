ichigyo プライバシーポリシー

いただく情報

「Google でログイン」で、Google Search Console のデータを読むだけの許可（https://www.googleapis.com/auth/webmasters.readonly）をいただきます。メールアドレス、氏名、そのほかの Google のデータはいただきません。

使い道

いただいた許可は、利用者ご本人の Claude Code の作業環境の中だけで使い、ご本人のサイトの検索キーワードや表示回数を読んで、記事のリライト候補を選ぶためだけに使います。

保存と共有

許可の鍵は利用者ご本人の Claude Code の環境（ご本人だけが見られる場所）に保存されます。運営者のサーバーには保存せず、第三者に渡したり売ったりしません。

ichigyo による Google API から受け取った情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

やめるとき

Google アカウントの「サードパーティ製のアプリとサービス」から ichigyo を削除すると、いつでも許可を取り消せます。
